# Fashion Sales Dashboard (Excel)

# Overview
Developed an interactive Fashion Sales Dashboard in Microsoft Excel to analyze sales performance, monitor revenue trends, and identify high-performing products and regions. The dashboard enables users to explore sales data through interactive charts, PivotTables, and slicers.

---

# Business Problem
Retail businesses need a centralized dashboard to monitor sales performance, identify top-selling products, analyze regional sales, and support data-driven business decisions.

---

# Objectives
- Analyze overall sales performance.
- Monitor monthly sales trends.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Create an interactive dashboard for business users.

---

# Dataset
- Fashion Sales Dataset
- Cleaned and analyzed using Microsoft Excel
- Interactive reporting using PivotTables and PivotCharts

---

# Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Dashboard Design

---

# Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Monthly Sales Trend
- Sales by Region
- Sales by Product Category
- Interactive Slicers

---

# Key Insights
- Identified the highest revenue-generating product category.
- Compared sales performance across regions.
- Analyzed monthly sales fluctuations.
- Enabled interactive filtering for faster business analysis.
